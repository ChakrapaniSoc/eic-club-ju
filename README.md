# EMBEDEX Innovators Club — Joy University

A responsive, single-page club website built with plain HTML, CSS and JavaScript.

## Features
- Responsive navigation and hero section
- Auto-advancing events carousel with clickable detail modals
- Club introduction and mission
- Auto-rotating 3D-style team member carousel
- Achievements section
- Contact and social link area

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Before publishing
Replace the sample event cards and descriptions with confirmed club events. Add real member names, roles and photos. Update the club email and Instagram links in the contact/footer area.
